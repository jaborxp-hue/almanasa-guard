# 🛡 حارس المنصة

## ماذا يفعل حارس المنصة؟

| الخيار | ماذا يحدث | لماذا |
|---|---|---|
| 🚫 حظر يوتيوب نهائياً | إزالة يوتيوب وكل نسخه من الجهاز ومنع عودته | المحتوى غير المراقَب والمقاطع القصيرة المُدمنة |
| 🧹 إزالة التطبيقات غير الضرورية | حذف تطبيقات الشركة المصنّعة والألعاب والإعلانات حتى المحمية منها | تسريع الجهاز وإغلاق أبواب المحتوى غير المناسب |
| 🌐 فلتر عائلي (DNS) | حجب المواقع الإباحية والضارة والإعلانات على مستوى الجهاز كله | حماية في كل التطبيقات والمتصفح |
| 🔒 قفل متجر التطبيقات | الطفل لا يستطيع تنزيل تطبيقات جديدة | يبقى القرار بيد الوالدين |
| ⚡ تسريع وتنظيف | تنظيف الملفات المؤقتة وتسريع الحركة وتحسين التطبيقات | شاشة أسرع وأخف |
| ↩️ سجلّ واسترجاع | كل تغيير محفوظ ويمكن إرجاعه بضغطة | لا شيء يضيع للأبد |

كل الإعدادات محمية **برقم سري** يختاره الوالدان، والحارس يعيد تطبيق الحماية تلقائياً بعد كل تشغيل للجهاز وكل 3 ساعات، فلا يستطيع الطفل إرجاع ما تغيّر.

## مستويا القفل

- **المستوى الأول — الحماية الأساسية:** يحذف ويحظر ويُفلتر، ويمكن للوالدين التراجع عن أي شيء من داخل التطبيق بالرقم السري. مناسب لأغلب البيوت.
- **المستوى الثاني — القفل الكامل:** يجعل الحارس «مالك الجهاز» فلا يمكن حذفه أو تعطيله من الإعدادات، ويمنع إعادة ضبط المصنع من القائمة. *(قيد التطوير)*

## خطوات التشغيل

1. **فعّل وضع المطوّرين:** الإعدادات ← حول الجهاز ← اضغط على «رقم الإصدار» (Build) سبع مرات.
   - تلفزيون TCL / أندرويد TV: الإعدادات ← تفضيلات الجهاز ← حول ← رقم الإصدار.
   - سامسونج / شاومي: الإعدادات ← حول الهاتف ← معلومات البرنامج ← رقم الإصدار (أو «إصدار MIUI»).
2. **فعّل «تصحيح أخطاء USB» و«تصحيح الأخطاء عبر الشبكة»** من قائمة خيارات المطوّرين.
3. **ثبّت حارس المنصة** من رابط التحميل أعلاه (اسمح بالتثبيت من مصادر غير معروفة إذا طُلب منك).
4. افتح التطبيق واتبع الشرح خطوة بخطوة، وعند ظهور رسالة «السماح بتصحيح الأخطاء» اختر **السماح دائماً**.
5. اختر رقماً سرياً لا يعرفه الأطفال.

## الخصوصية

لا يجمع الحارس أي بيانات، ولا يرسل شيئاً إلى أي خادم. كل العمل يتم داخل جهازك فقط.
